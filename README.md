# 🌦️ WeatherBot – Your Personal Weather Assistant  

## 📌 About the Project  
WeatherBot is a simple **Python-based chatbot** that provides real-time weather updates for any city.  
It uses the **OpenWeatherMap API** to fetch current weather conditions and temperature.  

---

## ✨ Features  
- Get real-time weather updates 🌤️  
- Beginner-friendly Python code 🐍  
- Interactive chatbot 🤖  
- Powered by [OpenWeatherMap API](https://openweathermap.org/api)  

---

## 🛠️ Tech Stack  
- Python 3  
- Requests library  
- OpenWeatherMap API  

---
